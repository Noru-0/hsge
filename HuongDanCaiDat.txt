# Hướng dẫn cài đặt môi trường — HSGE

## 1. Hệ điều hành & cấu hình tối thiểu

- **Hệ điều hành**: Windows 10/11, macOS 13+, Linux (Ubuntu 22.04+ / CentOS 8+).
- **Cấu hình tối thiểu**:
  - CPU 4 nhân, RAM 8 GB, ổ cứng 10 GB trống.
  - GPU không bắt buộc (mock pipeline chạy hoàn toàn trên CPU).
  - Để chạy real WebArena cần kết nối mạng ổn định và API key cho LLM.

## 2. Công cụ & phiên bản

| Công cụ | Phiên bản | Ghi chú |
|---|---|---|
| Python | ≥ 3.10 | Ngôn ngữ chính |
| Conda | ≥ 23.x | Quản lý môi trường (khuyến nghị) |
| Git | ≥ 2.30 | Quản lý phiên bản |
| Playwright | (cài qua pip) | Trình duyệt cho WebArena real run |
| Node.js | ≥ 18 | Playwright cần Node.js để cài Chromium |

**Thư viện Python chính** (xem `requirements.txt`):

- `numpy` — phụ thuộc cứng duy nhất cho mock pipeline.
- `openai`, `anthropic` — LLM backend thực tế.
- `sentence-transformers` — Embedder thực tế.
- `browsergym-core`, `browsergym-webarena` — WebArena runtime.
- `pyyaml` — đọc `config.yaml`.
- `python-dotenv` — đọc biến môi trường từ `.env`.
- `pillow` — xử lý ảnh (screenshot, Set-of-Marks).
- `pytest` — chạy kiểm thử.

## 3. Cài đặt môi trường

### 3.1. Cài đặt Python & Conda

Tải và cài **Miniconda** (khuyến nghị):
```
https://docs.anaconda.com/miniconda/
```

Sau khi cài, mở **Anaconda Prompt** (Windows) hoặc terminal (macOS/Linux).

### 3.2. Tạo môi trường Conda

```bash
conda create -n hsge python=3.12 -y
conda activate hsge
```

### 3.3. Cài đặt thư viện

#### Mock pipeline (chạy thử không cần API key)

```bash
pip install numpy
```

#### Real pipeline (WebArena, LLM thật)

```bash
pip install -r requirements.txt
```

Sau đó cài trình duyệt cho Playwright:

```bash
playwright install chromium
```

## 4. Cấu hình biến môi trường

Tạo file `.env` trong thư mục gốc của dự án (bên cạnh `config.yaml`):

```bash
# LLM Provider (chọn 1 trong 2)
OPENAI_API_KEY=sk-your-key
DEEPSEEK_API_KEY=sk-your-key

# WebArena site URLs (thay bằng URL thật của instance bạn)
WA_SHOPPING=http://your-host:7770
WA_SHOPPING_ADMIN=http://your-host:7780
WA_REDDIT=http://your-host:9999
WA_GITLAB=http://your-host:8023
WA_WIKIPEDIA=http://your-host:8888
WA_MAP=http://your-host:9090
WA_HOMEPAGE=http://your-host:4399

# Tài khoản đăng nhập (nếu instance dùng seed khác mặc định)
WA_SHOPPING_USERNAME=...
WA_SHOPPING_PASSWORD=...
WA_REDDIT_USERNAME=...
WA_REDDIT_PASSWORD=...
WA_GITLAB_USERNAME=...
WA_GITLAB_PASSWORD=...
WA_SHOPPING_ADMIN_USERNAME=...
WA_SHOPPING_ADMIN_PASSWORD=...
```

### 4.1. Cấu hình `config.yaml`

Các tham số không phải bí mật được cấu hình trong `config.yaml`.
Thứ tự ưu tiên: **CLI flag > config.yaml > built-in default**.

Xem file `config.yaml` để biết danh sách đầy đủ các tham số.

## 5. Kiểm tra cài đặt

### Mock pipeline

```bash
conda activate hsge
python explore.py
```

Kết quả kỳ vọng: script chạy không lỗi, hiển thị output exploration loop.

### Kiểm thử đơn vị

```bash
python -m pytest hsge/tests/ -q
```

Kết quả kỳ vọng: tất cả test đều pass (không có FAILED).

### Dry-run WebArena

```bash
python run_webarena.py --dry-run --out /tmp/wa_dry --max-nodes 2
```

Kết quả kỳ vọng: script chạy thành công, tạo file trong thư mục output.

## 6. Lưu ý

- Dự án **không đính kèm** thư viện, file build, cache, log hoặc file trung gian trong kho mã nguồn.
- Tất cả thư viện được cài qua pip; không có file `.whl` hoặc `.tar.gz` đính kèm.
- Thư mục `.auth/` (cache session đăng nhập) được tạo tự động khi chạy real run và đã nằm trong `.gitignore`.
- Thư mục `outputs/` chứa kết quả chạy và cũng được git-ignore.

## 7. Lỗi thường gặp

| Lỗi | Nguyên nhân | Cách khắc phục |
|---|---|---|
| `ModuleNotFoundError: No module named 'numpy'` | Chưa cài numpy | `pip install numpy` |
| `openai.error.RateLimitError` | Vượt quota API | Đợi hoặc nâng cấp tài khoản |
| `playwright install chromium` fails | Thiếu Node.js hoặc network | Cài Node.js v18+, chạy lại |
| `browsergym` import error | Chưa cài browsergym | `pip install browsergym-core browsergym-webarena` |
| `KeyError: 'WA_SHOPPING'` | Thiếu biến môi trường trong `.env` | Kiểm tra lại file `.env` |
| `Connection refused` khi chạy real run | WebArena instance chưa chạy | Khởi động WebArena trước |

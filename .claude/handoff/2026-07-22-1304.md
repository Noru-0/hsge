## 3. Decisions & rationale

- **Adjudication chỉ ở dải biên, không đổi ngưỡng đơn.** Đo wa_run_09: cặp
  synonym thật=0.570, cặp khác nghĩa=0.606, nằm hai bên 0.6 → không ngưỡng đơn
  nào tách được. Band = `sim_threshold ± 0.15`. **Loại** phương án hạ
  `predicate_sim` (bằng chứng cho thấy vô ích) và phương án bật lại online-merge
  (sẽ hồi tố gộp id đã bake vào operator).
- **Resume = pickle**, không JSON. Discovery objects giữ numpy centroid; JSON tự
  serialize sẽ nhiều code mong manh. Resume chạy cùng code version nên pickle
  không gặp vấn đề đổi class. **Loại** JSON-serializer và hybrid.
- **Backend detach tại chỗ trong runtime** (không thêm `__getstate__` vào class
  production) — giữ surgical. Re-inject bằng cách copy backend từ explorer mới
  dựng vào object vừa unpickle. `verify_contexts_fn` (lambda) cũng phải detach.
- **Checkpoint atomic mỗi node** (`.tmp` + `os.replace`) để sống sót hard-kill;
  node dở làm lại từ đầu. **Không cần signal handler** — mọi cách kill đều an
  toàn vì checkpoint nằm sẵn trên đĩa sau node xong.
- **Guard mới**: có `checkpoint.pkl` mà không `--resume` → **báo lỗi dừng** (trước
  đây âm thầm truncate `run_log.jsonl` + ghi đè).
- **Deviation spec resume**: bỏ cảnh báo embedder-model-mismatch (tránh probe
  thuộc tính mong manh; dựa vào resume cùng config).
- **Bug UTF-8**: chỉ file axtree `.txt` (text thô) mới crash; các `*.json` dùng
  `json.dump` mặc định `ensure_ascii=True` nên escape thành ascii, **không**
  crash — nhưng vẫn thêm encoding cho phía đọc. Test giả lập cp1252 bằng patch
  `builtins.open` để RED được trên macOS.
- **Sự cố mạng máy Mac (đã khép lại)**: shopping/reddit chết vì máy Mac
  `192.168.1.29` mất route tới LAN `192.168.1.31` (ping gateway `.1` cũng fail;
  6 utun/VPN — Cloudflare WARP + OpenVPN agent). **auth.py hoàn toàn đúng** —
  lỗi ở `page.goto` tầng mạng, trước mọi selector. User chuyển sang máy Windows
  + tunnel `trycloudflare.com`, nên chuyện mạng Mac không còn liên quan.
